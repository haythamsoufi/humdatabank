# Экспорт и скачивание данных

Используйте это руководство, чтобы скачать данные заданий для анализа или отчетности (например, в Excel или PDF).

## Прежде чем начнёшь

- Вам нужен доступ к заданию, которое вы хотите экспортировать.
- В шаблоне должны быть включены функции экспорта (экспорт в Excel и/или PDF).
- Экспорт возможен с **страницы формы** при заполнении или просмотре задания.

## Экспортные данные

### Экспорт со страницы формы записи

Опции экспорта доступны, когда вы находитесь на странице формы записи на присвоение (заполнение или просмотр формы):

1. **Перейти к форме назначения**:
   - Из вашего **Dashboard** откройте задание, которое хотите экспортировать.
   - Или, если вы администратор: откройте **Панель администраторов** → **Управление формами и данными** → **Управление назначениями**, затем кликните на страну/организацию в назначении, чтобы открыть форму заявки.

2. **Экспортировать шаблон Excel** (если включено):
   - Нажмите кнопку **В Excel Options** (или пункт меню) в интерфейсе формы.
   - Нажмите **Export Data Template (.xlsx)**, чтобы скачать файл Excel со структурой формы и текущими данными.
   - Файл Excel может использоваться для заполнения данных офлайн и затем импортироваться обратно.

3. **Экспортировать PDF** (если включено):
   - Нажмите кнопку **Экспортировать PDF** в интерфейсе формы.
   - Будет сгенерирована и скачана PDF-версия формы с актуальными данными.
   - Это полезно для печати или архивирования заявок.

**Примечание**: Функции экспорта должны быть включены администратором в шаблоне. Если вы не видите опции экспорта, возможно, в шаблоне эти функции не включены.

## Советы

- Всегда поддерживайте согласованность экспортируемого имени файла (точка + шаблон + область объёма).
- Если сравнивать между периодами, по возможности сохраняйте одну и ту же шаблонную версию.
- Если в экспорте есть ID/коды, сохраняйте их (они помогут позже присоединиться к наборам данных).

## Общие проблемы

- **В экспорте отсутствует страна**: страна может не быть частью задания, или она ещё не отправлена, либо ваш экспортный фильтр исключает её.
- **Числа не совпадают с формой**: проверьте, экспортировали ли вы другую версию/период шаблона, или применяются ли вычисления/округление при экспорте.
- **Экспорт занимает слишком много времени**: экспорт меньших объёмов (по одному заданию за раз) или меньшего количества стран.
