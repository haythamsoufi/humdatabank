## Langage

La documentation est affichée dans la langue sélectionnée dans **Paramètres du compte**. Les langues prises en charge par les guides incluent **anglais**, **français**, **espagnol**, **arabe** et **russe**. Si une page n’est pas encore traduite, la version anglaise est affichée.
