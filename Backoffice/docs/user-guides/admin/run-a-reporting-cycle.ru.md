# Запустите цикл отчётности (админская стратегия)

Используйте этот сценарий, когда нужно провести раунд коллекции от конца до конца (от подготовки шаблона до экспорта одобренных данных).

## Прежде чем начать

- Для шаблонов и заданий нужен **администратор** доступ.
- Согласоваться внутренне по вопросам:
  - название отчетного периода (пример: «2026 Q1»)
  - список стран-участниц
  - что означает «хорошее качество» (обязательные документы, ожидания валидации)

## Шаг 1 — Подготовьте шаблон

1. Открыть **Панель администраторов** → **Управление формами и данными** → **Управление шаблонами**.
2. Откройте шаблон, который будете использовать.
3. Подтвердите, что шаблон таков:
   - clear (метки/help текст)
   - не слишком строгие (разумно требовательные поля)
   - Согласованность (стандартизированы варианты выпадающего списка)
4. Если вы внесли правки, проверьте с небольшим черновиком.

Совет: Для сложных изменений следите за [Form Builder (advanced)](form-builder-advanced.md).

## Шаг 2 — Создайте задание

1. Открыть **Панель администраторов** → **Управление формами и данными** → **Управление назначениями**.
2. Нажмите **Создать** (или что-то подобное).
3. Выбирайте:
   - шаблон
   - включенные страны (или организации)
   - дата начала и крайний срок
4. Добавьте короткое сообщение с инструкцией:
   - Что тебе нужно
   - крайний срок
   - к кому обращаться по вопросам

## Шаг 3 — Подтвердите доступ (до запуска)

Для каждой страны:
- Подтвердить, что фокусные точки имеют:
  - правильная роль присвоения (ввод данных)
  - правильный доступ к стране

Если вы ожидаете подтверждающие документы:
- Подтвердить, что нужные пользователи имеют роль, разрешающую загрузку (см. [Поддерживающие документы (admin)](supporting-documents.md)).

## Шаг 4 — Отслеживайте ход сбора

Во время открытого периода следите:
- Не начал
- в процессе
- отправлен
- просроченным

Что делать, когда прогресс низкий:
- отправлять напоминания (короткие + конкретные)
- уточнение запутанных полей (метки/help текст)
- продлить сроки, если ваш рабочий процесс это позволяет

## Шаг 5 — Проверьте и одобрите поданные материалы

1. Откройте задание.
2. Проверьте заявки по следующим вопросам:
   - недостающие значения, которые должны существовать
   - выбросы (значения далеко за пределами ожидаемого диапазона)
   - обязательные документы (если применимо)
3. Одобрять работы, соответствующие минимальному стандарту качества.
4. Переоткрывать/возвращать материалы, требующие исправления (с кратким объяснением, что исправить).

Совет: используйте [Статусы подачи и то, что вы можете сделать](../common/submission-statuses-and-permissions.md), чтобы объяснить, почему «Редактировать/Отправить» заблокировано/разблокировано.

## Шаг 6 — Экспорт данных для отчётности

1. Перейдите на страницу формы заявки для каждого задания или страны, которую хотите экспортировать:
   - Открыть задание из **Управлять заданиями**.
   - Нажмите на страну/организацию, чтобы открыть форму заявки.
2. Используйте опции экспорта, доступные на странице формы заявки:
   - **Экспортировать шаблон Excel** (если включено): Скачивает файл Excel со структурой формы и данными.
   - **Экспортировать PDF** (если включено): Скачает PDF-версию формы с актуальными данными.
3. Сохраняйте экспортированные файлы с единой схемой именования:
   - `2026-Q1_TemplateName_CountryName.xlsx` (для экспорта отдельных стран)
   - Примечание: экспорт ведётся по стране/организациям, а не для всех стран одновременно из списка назначений.
4. Если нужен повторяемый анализ, сохраняйте ID/коды при экспорте (не удаляйте их).

Для рекомендаций по интерпретации см. [Exports: how to interpret files](exports-how-to-interpret.md).

## Шаг 7 — Закрыть и задокументировать решения

В конце цикла:
- Фиксировать любые изменения в середине цикла (продления сроков, обновления шаблонов).
- Зафиксируйте правило для дублирования (особенно для публичных публикаций).
- Фиксировать известные проблемы для улучшения в следующем цикле.

## Распространённые проблемы

- **Страна не может видеть задание**: отсутствуют роли и доступ к стране.
- **Пользователи не могут отправлять материалы**: слишком много обязательных полей или строгая валидация; Добавьте текст помощи и сократите требования.
- **Изменения шаблона вызвали путаницу**: избегайте крупных правок в середине цикла; Запуск через новое задание.
- **Экспорт не соответствует ожиданиям**: подтвердите, что вы экспортировали правильную версию назначения и шаблона.
