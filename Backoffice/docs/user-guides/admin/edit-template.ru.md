# Редактировать шаблон формы (Form Builder)

Используйте это руководство, когда нужно обновить существующий шаблон (вопросы и разделы будут заполнены).

## Прежде чем начать

- Вам нужен **Администратор** доступ с разрешениями шаблона.
- Проверить, используется ли шаблон уже (имеет активные назначения).
- Определите, какие изменения вам нужны:
  - **Safe**: метка/help исправления текста, добавление необязательных полей, изменение порядка разделов.
  - **Рискованно**: изменение типов полей, изменение необходимых правил, удаление полей (может нарушить согласованность между странами).

## Откройте шаблон

1. Открыть **Панель администраторов** → **Управление формами и данными** → **Управление шаблонами**.
2. Найдите шаблон и откройте его.
3. Если система показывает несколько версий (черновик/опубликованный), начните с **последнего черновика** (или, если необходимо, создайте новую версию).

## Распространённые правки (пошагово)

### Добавить новый раздел

1. Нажмите **Добавить раздел**.
2. Дайте разделу чёткое название (это становится навигационным элементом для фокусных точек).
3. Сохранить.

### Добавить новое поле

1. Откройте раздел, где хотите появляться поле.
2. Нажмите **Добавить поле**.
3. Выберите тип поля (текст/номер/дата/выпадающее меню и т.д.).
4. Установите **label** (ровно то, что пользователи увидят).
5. Если доступно, добавьте **help text** (одно короткое предложение).
6. Устанавливать **Обязательно** только тогда, когда действительно нужно.
7. Сохранить.

### Обновите ярлык или смс помощи

1. Откройте поле.
2. Измените текст label/help, чтобы он соответствовал желаемому смыслу.
3. Сохранить.

### Перестановка секций или полей

1. Используйте ручку перетаскивания (или управление движением) для перестановки.
2. Сохранить.

## Типы полей (что выбрать)

- **Текст**: имена, заметки, краткие объяснения.
- **Число**: счёты и величины. Предпочитайте число, когда нужны итоги или подтверждение.
- **Дата**: свидания (не свободный текст).
- **Выпадающее меню / одиночный выбор**: когда ответы должны быть единообразными в разных странах.
- **Мультивыбор**: когда может применяться несколько ответов.
- **Матрица / таблица** (если доступна): повторяющиеся значения в разных категориях. Используй, когда пользователям нужно ввести одну и ту же меру для нескольких строк.

## Валидация и обязательные поля

- Отметить поле **обязательным** только тогда, когда оно должно быть доступно для использования подачи.
- Если пользователей часто блокируют по адресу **Отправить**, сократьте необходимые поля или добавьте более понятные инструкции.
- При изменении правил валидации сначала проверьте влияние с помощью небольшого задания.

## Связь с индикаторным банком (когда это применимо)

Если ваш рабочий процесс использует **Индикаторный банк**:

- Привязать поле к индикатору, когда нужны стандартизированные определения и последовательная отчетность.
- Сохраняйте метку поля удобной для пользователя, даже если название индикатора техническое.
- Избегайте связывания нескольких разных вопросов с одним и тем же показателем, если они действительно не представляют одну и ту же меру.

## Публикация и тестирование

1. Сохраняйте свои изменения в черновиках.
2. Если ваша система требует публикации, **публикуйте** новую версию.
3. Создайте небольшое тестовое задание (в одной стране) и выполните его сами.
4. Исправьте все запутанные метки и уберите ненужные обязательные поля.

## Распространённые проблемы

- **Мои изменения не отображаются для фокусных точек**: шаблонная версия может не быть опубликована или задание может использоваться на более старой опубликованной версии.
- **Пользователи не могут отправить после моего изменения**: обязательное поле или новая валидация блокируют отправку — протестируйте форму как ключевую точку.
- **Данные выглядят несогласованными между странами**: избегайте изменения типов полей/то есть во время сбора; Создайте новый шаблон/версию и сообщите об изменениях.
