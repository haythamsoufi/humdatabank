# Начало

Этот раздел помогает вам ориентироваться и начать пользоваться бэк-офисом.

## Быстрый старт

- Для пошаговых инструкций начинайте с [Start here](start-here.md).
- Если вы новичок, сначала прочитайте [How the platform works](how-it-works.md).

## Что ты можешь сделать здесь

- Понимание основных областей платформы
- Изучите основные рабочие процессы для вашей роли
- Найти местоположение объектов в интерфейсе

## Первые шаги

1. Войдите в систему и откройте свой **Dashboard**
2. Установить свой **Язык** в [Account settings](account-settings.md)
3. Откройте [View your assignments](../user-guides/focal-point/view-assignments.md), чтобы найти формы, которые нужно заполнить.

## Нужна помощь?

- См. [Start here](start-here.md) и руководства в боковой панели документации
- См. [Getting help](../user-guides/common/getting-help.md)
- Если вам всё ещё нужна помощь, свяжитесь с администратором или каналом поддержки вашей организации
