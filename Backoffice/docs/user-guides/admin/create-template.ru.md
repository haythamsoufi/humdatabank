# Создать шаблон формы

Используйте это руководство для создания шаблона формы (структуры, которую позже будете назначать странам).

## Прежде чем начнёшь

- Тебе нужен **Администратор** доступ.
- Уточните, какую информацию нужно собирать (вопросы, форматы, ссылки на индикаторы).

## Шаги

1. Открыть **Панель администраторов** → **Управление формами и данными** → **Управление шаблонами**.
2. Нажмите **Создать шаблон**.
3. Введите шаблон **name** и (по желанию) **описание**.
4. Добавьте один или несколько **разделов** для организации формы.
5. Внутри каждого раздела добавьте **поля** (текст, номер, дата, выпадающее меню и т.д.).
6. Для полей, которые должны использовать стандартные определения, свяжите их с **Индикаторным банком** (если применимо).
7. Сохраните шаблон.

## Советы

- Используйте чёткие метки (точный текст, который увидят пользователи).
- Сгруппировать связанные вопросы по разделам.
- Отмечайте поля как **required** только при необходимости.
- Сначала проверьте шаблон, создав небольшое задание.

## Общие проблемы

- **Ключевые точки путаются из-за поля**: перепишите метку и добавьте короткий справочный текст (если доступен).
- **Слишком много обязательных полей**: пользователей блокируют при отправке — поля для отметки нужны только тогда, когда действительно нужны.
