# Отправить данные формы

Используйте это руководство, чтобы выполнить задание и отправить форму.

## Прежде чем начнёшь

Отмечайте каждый пункт перед началом:

- [ ] **Текущее назначение** видимое на вашей панели управления. Если их нет, см. [Troubleshooting](troubleshooting.md) ("Задания не отображаются").
- [ ] **Ваши данные** — цифры или ответы для каждого раздела формы.
- [ ] **Ваш источник данных**, если в форме есть поля комментариев для документирования источников.
- [ ] **(Если применимо) Поддерживающие документы** — любые файлы для ссылки или загрузки.

## Шаги

1. Из вашего **Dashboard** откройте задание, которое хотите выполнить.
2. Используйте левую боковую панель для навигации между **разделами** формы.
3. Заполните поля. Обязательные поля отмечены звездочкой (*).
4. Проверьте наличие сообщений о валидации и исправьте их.
5. Когда будете готовы, нажмите **Отправить**, чтобы завершить данные.

## Спасая свой прогресс

- Твоя работа обычно сохраняется по ходу дела.
- Ты можешь уйти и вернуться позже.
- Если вы видите опцию **Сохранить черновик**, вы можете использовать её для явного сохранения.

## Советы

- Используйте поля комментариев для документирования источников данных (если доступны).
- Если вы не можете отправить, ищите отсутствующее требуемое поле или ошибку валидации.
