# Рецепты ролей (распространённые административные задачи)

Используйте эту страницу, если не уверены, какие роли назначить для конкретной задачи.

## Прежде чем начать

- Роли контролируют **какие страницы/действия** пользователь может получить доступ.
- Многим пользователям также нужен **доступ к стране**, чтобы видеть назначения для конкретных стран.

## Рецепт: Стандартная точка фокуса (ввод данных)

Дайте пользователю:

- Роль: `assignment_editor_submitter`
- Доступ к стране: назначить хотя бы одну страну

Они могут:

- просмотр назначений для своих стран
- ввести данные и отправить

## Рецепт: Ключевой человек, который тоже одобряет

Дайте пользователю:

- Роли: `assignment_editor_submitter`, `assignment_approver`
- Доступ к стране: назначение соответствующих стран

## Рецепт: Просмотр только для чтения

Дайте пользователю:

- Роль: `assignment_viewer`
- Доступ к стране: необязательный (зависит от настройки вашей системы)

## Рецепт: дизайнер шаблонов (без управления пользователями)

Дайте пользователю:

- Роль управления шаблонами (например: `admin_templates_manager`)

По желанию также:

- `assignment_viewer` (чтобы они могли видеть, как используются шаблоны)

## Рецепт: менеджер заданий (без изменений шаблона)

Дайте пользователю:

- `admin_assignments_manager`

По желанию:

- `assignment_viewer` или `assignment_approver`, если они также рассматривают поданные материалы

## Рецепт: менеджер пользователей (HR / администратор доступа)

Дайте пользователю:

- `admin_users_manager`

Они могут создавать/управлять пользователями и назначать роли (в пределах разрешённого объёма).

## Рецепт: только загрузчик документов

Дайте пользователю:

- `assignment_documents_uploader`
- Доступ к стране (если это требуется по вашей системе)

Они могут загружать подтверждающие документы, но не отправлять данные формы.

## Распространённые проблемы

- **Пользователь не может видеть назначения**: обычно им нужны и (1) роль по назначению, и (2) доступ к стране.
- **Пользователь видит «Доступ запрещён»**: у него отсутствует конкретная роль для этого административного модуля.
