# Управление пользователями

Используйте это руководство, чтобы найти пользователей, обновить их данные и управлять доступом.

## Прежде чем начнёшь

- Тебе нужен **Администратор** доступ.

## Найдите пользователя

1. Открыть **Панель администраторов** → **Управление пользователями** → **Управление пользователями**.
2. Используйте поисковую строку, чтобы найти пользователя по **name** или **email**.
3. Откройте пользователю возможность просматривать или редактировать детали.

## Обновить информацию о пользователях

1. Откройте пользователю.
2. Во вкладке **User Details** обновите нужные поля (например: имя, должность, пароль).
3. Для обновления ролей выберите или отменьте их в разделе «Роли» (пользователи могут иметь несколько ролей).
4. Нажмите **Сохранить изменения**.

## Назначайте или удаляйте страны/организации (разрешения субъектов)

1. Откройте пользователю.
2. Перейдите во вкладку **Permissions of Entity**.
3. Добавить или удалить **страны** или **организации** (филиалы, подразделения НС и т.д.).
4. Нажмите **Сохранить изменения**.

## Деактивировать пользователя

1. Найдите пользователя в списке.
2. Нажмите **Деактивировать** (или переключить статус пользователя).
3. Подтвердите.

Деактивированные пользователи не могут войти, но их история сохраняется.

## Сбросить пароль

Если ваш рабочий процесс требует установки нового пароля для пользователя:

1. Откройте пользователю.
2. Установите новый пароль.
3. Сохранить.
4. Поделитесь новым паролем **безопасно**.

## Советы

- Если контактный пункт сообщает о недостающих данных, сначала проверьте **распределение стран**.
- Предпочитайте **деактивировать** аккаунты вместо их удаления.

## Общие проблемы

- **Пользователь не видит назначения**: подтвердите, что они являются центром и имеют хотя бы одну страну.
- **Пользователь не может получить доступ к странице администратора**: подтвердите, что его роль/права включают эту страницу.
