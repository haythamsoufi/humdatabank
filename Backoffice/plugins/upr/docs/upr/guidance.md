# UPR Guidance documents

Guidance documents are official UPR reference files (methodology, indicator definitions, form-filling instructions) that staff upload in **UPR Tools → Guidance**.

## How they are used

1. A System Manager uploads a file on the [UPR Tools Guidance tab](/admin/upr-tools#guidance).
2. An AI admin imports the same file from **Knowledge Base → Upload/Import → Guidance Documents**.
3. The chatbot can then retrieve those chunks when answering Unified Plan and Report questions.

Imported guidance stays **staff-only** by default. An admin can make a document public later from the Knowledge Base grid.

## Who can upload

- **UPR Tools → Guidance** — System Managers; documents are tagged as owner `upr`
- **Knowledge Base → Guidance Documents** — AI admins; uploads without a plugin context are tagged as owner `system`

Deleting a guidance document also removes any linked AI Knowledge Base copy (chunks and embeddings).
