# Как работает платформа

На этой странице основные элементы бэк-офиса объясняются простыми словами.

## Ключевые идеи (простой язык)

- **Шаблон**: структура формы (вопросы + разделы), которую создают администраторы.
- **Назначение**: когда администратор отправляет шаблон в одну или несколько стран для завершения.
- **Сдача формы**: когда фокусная точка завершает форму и нажимает **Отправить**.

## Типичный рабочий процесс

1. **админ** создаёт или обновляет **шаблон**.
2. Администратор создаёт **назначение** по этому шаблону и выбирает страну/страны.
3. Точка **фокуса** открывает задание, заполняет форму, исправляет сообщения подтверждения и нажимает **Отправить**.
4. Администраторы могут отслеживать прогресс (например: в ожидании / в процессе / отправке).

## Основные места, которые вы будете использовать

### Панель управления (все пользователи)

Ваша главная страница. Обычно там отображаются ваши текущие работы и быстрые ссылки.

### Настройки аккаунта (для всех пользователей)

Используйте **Настройки аккаунта**, чтобы обновить профиль, изменить пароль и выбрать предпочитаемый язык.

## Советы

- Используйте боковую панель для перемещения между разделами.
- Если не удаётся найти страницу, используйте поиск по платформе (если он включен) или спросите у администратора.

Теперь, когда вы поняли основы, руководство пользователя объясняет каждую задачу шаг за шагом.
