# Создать новое задание

Используйте это руководство, чтобы создать новое задание, которое распределит шаблон формы по странам для заполнения контактными пунктами.

## Прежде чем начнёшь

- Тебе нужен **Администратор** доступ.
- Вам нужен готовый **шаблон** с опубликованной версией.
- Ты должен знать, какие **страны** должны получить задание.

## Шаги

1. Открыть **Панель администраторов** → **Управление формами и данными** → **Управление назначениями**.
2. Нажмите **Создать новое задание**.
3. Выберите **шаблон**, который хотите распространять (появляются только шаблоны с опубликованными версиями).
4. Введите название **периода**:
   - Выберите **тип периода**: один год, годовой диапазон или месячный диапазон
   - Ввести соответствующие значения на основе выбранного типа периода
   - Система автоматически генерирует имя периода
5. Установите **крайний срок** (срок) для подачи данных (необязательно, но рекомендуется).
6. Перейдите на вкладку **Entity-Based Assignments**, чтобы выбрать:
   - **Страны**, которые должны получить это назначение, и/или
   - **NS Structure** сущности (ветви, подветви, локальные единицы) и/или
   - **Секретариат** структуры (подразделения, департаменты, региональные/кластерные офисы)
7. Если вы хотите разрешить публичные публикации без входа:
   - Проверьте **Сгенерировать публичный URL для этого задания**
   - По желанию проверьте **Public URL активен по умолчанию** для немедленной активации
8. Нажмите **Создать** (или **Сохранить всё**, если вы сделали выбор сущности).

## После того, как вы создаёте задание

- Будут уведомлены контактные пункты, назначенные в выбранные страны.
- Они увидят новую задачу на своей панели управления.
- Вы можете отслеживать прогресс на странице «Управление заданиями».

## Советы

- Устанавливать реалистичные сроки (важны часовые пояса и праздники).
- Держите инструкции краткими и конкретными (что нужно и когда нужно).
- Выберите описательное название периода, чтобы потом было легко определить задание.
- Начинайте с небольшого набора стран при тестировании нового шаблона.
- Могут быть назначены только шаблоны с опубликованными версиями.

## Общие проблемы

- **Невозможно создать назначение**: шаблон может не иметь опубликованной версии. Сначала опубликуйте шаблон.
- **Контактные точки не видят назначение**: подтвердите, что они назначены в страну, и назначение включает эту страну.
