{{ _('What Decision Maker is') }}

{{ _("Decision Maker brings together Unified Plan, Unified Report and FDRS data to help prepare Federation-wide decisions. It shows the evidence and raises prompts for people to review. It does not make decisions, and it never scores or ranks National Societies.") }}

{{ _('How it works') }}

  1. {{ _('Data.') }} {{ _("Plan and report submissions already in the Databank are read. Nothing is entered here.") }}
  2. {{ _('Your scope.') }} {{ _("Rows are limited to the countries you may see before anything is calculated, so totals and flags never include other countries.") }}
  3. {{ _('Metrics.') }} {{ _("Every number comes from one registered metric with a fixed definition, unit, source and set of valid breakdowns. The same definition feeds the pages, exports and the assistant.") }}
  4. {{ _('Rules.') }} {{ _("Each decision has rules with a threshold, for example a funding requirement that changed by 30 percent or more between rounds. A rule gives the same result on the same data every time.") }}
  5. {{ _('Flags.') }} {{ _("When a rule is triggered, a flag shows the exact values, the threshold, the comparison period and links to the evidence records behind it.") }}
  6. {{ _('Human review.') }} {{ _("You acknowledge, mark under review, resolve or dismiss a flag, add a note, and say whether it was useful, incorrect or expected. FDS uses this feedback to tune thresholds.") }}

{{ _('What the decisions watch') }}

{{ _('Purpose') }}{{ _('What is monitored') }}
{{ _('Prioritise countries and National Societies requiring greater Federation-wide support and attention') }} {{ _("A shortlist with reasons, not a ranking: countries meeting at least two of four signals in the latest plan round. The signals are a fast-growing requirement, a large share of the network's requirement, a heavy emergency load, and limited partner support.") }}
{{ _('Inform strategic planning and resource prioritisation') }} {{ _("Funding requirements and people to be reached, round-on-round change, concentration in a few countries, requirements not yet validated.") }}
{{ _('Understand the global footprint, capacity, reach and resources of the network') }} {{ _("Countries covered, requirements, people to be reached, PNS support and core and capacity indicators, with how complete each is.") }}
{{ _('Identify trends, gaps and inconsistencies requiring management attention') }} {{ _("Large changes between rounds, stalled reviews, overdue submissions, indicators with data unavailable and low reporting coverage.") }}
{{ _('Inform planning, monitoring and reporting for major emergencies and global initiatives') }} {{ _("Emergency operations requirements and people to be reached, and whether each is matched by the other.") }}
{{ _('Understand the collective contribution of Host National Societies, Partner National Societies and the Secretariat') }} {{ _("Requirement by funding source and Strategic Priority, how many PNS support each country, and PNS figures that come only from the host plan.") }}
{{ _('Support accountability and strategic dialogue with consistent evidence') }} {{ _("Whether evidence is complete, validated and comparable before it is used with National Societies, leadership or governance.") }}
{{ _('Answer cross-cutting strategic questions') }} {{ _("Comparable plan data across country, region, round, funding source and Strategic Priority, also available through the assistant.") }}

{{ _('Reading a decision workspace') }}

  • {{ _('Decision question and purpose') }}: {{ _("what the decision is for and who it is meant for.") }}
  • {{ _('Current evidence summary') }}: {{ _("the key metrics for the selected round and scope.") }}
  • {{ _('Attention flags') }}: {{ _("what the rules found, most severe first.") }}
  • {{ _('Trends and comparisons') }}: {{ _("how the main figure moved across rounds.") }}
  • {{ _('Data quality and coverage') }}: {{ _("how many expected submissions are in, and the validation mix. Read this before quoting a total.") }}
  • {{ _('Evidence records and lineage') }}: {{ _("the source record behind every figure and flag.") }}
  • {{ _('Methodology') }}: {{ _("how the numbers and rules are defined.") }}

{{ _('Terms you will see') }}

{{ _('Severity') }}
{{ _("Information, Review, Important and Urgent show how soon a person should look at a flag. They do not rate how serious a situation is.") }}
{{ _('Validation') }}
{{ _("Validated means approved. Provisional means submitted or in review. Draft means not yet submitted and is left out of totals.") }}
{{ _('Data states') }}
{{ _("A reported zero is a real zero. Not applicable, data unavailable and not reported are different states and are never treated as zero or as a low value.") }}
{{ _('Readiness') }}
{{ _("Ready, Partial or Limited, based on how many expected submissions have been received. The bands are provisional.") }}
{{ _('Provisional threshold') }}
{{ _("An example value awaiting FDS approval. It is not policy.") }}
{{ _('Evidence ID') }}
{{ _("A stable reference to the exact record a figure came from. Use it to trace or cite a number.") }}

{{ _('Limits to keep in mind') }}

  • {{ _("Flags are prompts for follow-up, not conclusions. Check the evidence and the submission context first.") }}
  • {{ _("Only Databank data is used. GO and ERP are not connected, so live emergency and operational data are not included.") }}
  • {{ _("Funding figures are planned requirements, not confirmed income or spending.") }}
  • {{ _("An empty value means nothing was reported, not that the answer is zero.") }}
  • {{ _("The assistant explains the evidence and suggests questions. Flags come only from the rules.") }}

{{ _('Changing thresholds') }}

{{ _("Decisions, rules and thresholds are set in the product configuration, not in this tool. To change one, ask the FDS team. Every flag names the rule and threshold that raised it.") }}
