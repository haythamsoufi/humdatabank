# Управление заданиями

Используйте это руководство для просмотра, редактирования и управления существующими назначениями, которые распространяют шаблоны форм по странам.

## Прежде чем начнёшь

- Тебе нужен **Администратор** доступ.
- В системе должно быть как минимум одно существующее задание.

## Просмотр заданий

1. Открыть **Панель администраторов** → **Управление формами и данными** → **Управление назначениями**.
2. Ознакомьтесь со списком всех заданий.
3. Посмотрите название периода, шаблон, статус подачи и статус публичного URL каждого назначения.

## Отслеживайте ход заданий

Из списка заданий вы можете:

- Посмотрите, какие страны **не начаты / в процессе / отправлены**
- Выявление **просроченных** подач
- Просмотр прогресса подачи заявок по странам
- Открыть задание для проверки деталей

## Редактировать задание

1. Найдите задание в списке.
2. Нажмите на значок **edit** (карандаш).
3. Обновите нужные поля:
   - **Шаблон**: Изменить шаблон формы (если нужно)
   - **Название периода**: Обновление названия назначения
   - **Крайний срок**: Продлить или изменить срок подачи заявок
4. Добавить больше стран:
   - Используйте раздел **Добавить страны**
   - Выберите страны и нажмите **Добавить**
5. Нажмите **Сохранить изменения**.

## Управление публичными URL

### Сгенерировать публичный URL

1. Найдите задание в списке.
2. Нажмите **Generate Public URL** (если ещё не создано).
3. Публичный URL позволяет отправлять материалы без входа.

### Переключение статуса публичного URL

1. Найдите задание с публичным URL.
2. Нажмите на переключатель, чтобы **активировать** или **деактивировать** публичный URL.
3. При активном состоянии доступен публичный URL. При неактивном режиме подачи отключаются.

### Скопировать публичный URL

1. Найдите задание с публичным URL.
2. Нажмите **Скопировать URL**, чтобы поделиться с внешними пользователями.

## Просмотр публичных материалов

1. На странице заданий нажмите **Просмотреть все публичные заявки**, чтобы увидеть все публичные заявки.
2. Или нажмите **Просмотреть заявки** для конкретного задания, чтобы увидеть работы только по этому заданию.
3. Вы можете одобрять, отклонять или рассматривать материалы.

## Удалить задание

1. Найдите задание в списке.
2. Нажмите на иконку **delete** (мусор).
3. Подтвердить удаление.

**Внимание**: Это удалит назначение и все связанные с ним статусы страны и данные. Это действие нельзя отменить.

## Вид временной линии

1. На странице заданий нажмите **Просмотр временной шкалы**.
2. Просматривайте все задания на хронологии/диаграмме Ганта, чтобы визуализировать сроки и перекрывающиеся задания.

## Советы

- Регулярно следить за панелью на предмет просроченных подач.
- Используйте просмотр временной шкалы для предотвращения конфликтов в расписании.
- Продлевать сроки проактивно, если многие страны испытывают трудности.
- Публичные URL полезны для внешнего сбора данных, но требуют мониторинга.
- Регулярно проверять публичные материалы для обеспечения качества данных.

## Общие проблемы

- **Координатор сообщает, что не может увидеть задание**: подтвердить, что он назначен в эту страну, и задание включает эту страну.
- **Просроченные подачи**: отправьте напоминание и рассмотрите возможность продления срока при необходимости.
- **Публичный URL не работает**: проверьте, активирован ли он и активен ли назначение.
