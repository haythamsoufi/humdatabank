# Просмотрите свои задания

Ваша панель управления показывает формы, назначенные вам (и их статус).

## Прежде чем начнёшь

- Вам нужен доступ **Focal point** (или администратор, выступающий в роли фокусной точки).
- Ты должен быть назначен хотя бы в одну **страну**.

## Шаги

1. Откройте свою **Dashboard**.
2. Проверьте карточки заданий (название, крайний срок и статус).
3. Нажмите на задание, чтобы открыть форму.

## Понимание статуса задания

| Статус | Значение |
|--------|---------|
| **Ожидается** | Ещё не начал |
| **В процессе** | Начато, но не отправлено |
| **Отправлено** | Завершено и отправлено |
| **Просрочен** | Дедлайн просшёл, не отправлен |

## Советы

- Начинайте заранее, чтобы избежать проблем в последний момент.
- Ваш прогресс обычно **сохраняется автоматически** по мере работы.
- Если вы не видите ожидаемое задание, свяжитесь с администратором.
